## Project Description:
A simple digital library management system implemented in Java using object-oriented programming (OOP) principles.

## Main Objectives:
- Apply OOP concepts:
  - Encapsulation
  - Inheritance (e.g., PaperBook, EBook extending Book)
  - Polymorphism
  - Interfaces (if extended)
- Practice with Git and GitHub for version control.
- Develop logical problem-solving skills.

## Project Structure:
- `Book.java` – Abstract class representing a book.
- `PaperBook.java` – Represents a physical book.
- `EBook.java` – Represents a digital book.
- `Borrower.java` – Manages borrower data and actions.
- `BorrowingProcess.java` – Handles borrowing and return processes.

## How to Run:
This is a console-based Java application. To run:
1. Compile all `.java` files using `javac *.java`
2. Create a main method in a `Main.java` file to test functionality.
3. Run with `java Main`.
